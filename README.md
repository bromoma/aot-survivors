# Атака титанов: Survivors

Фан-игра в жанре survivors по мотивам «Атаки титанов»: летаешь на тросах УПМ, набираешь высоту и срезаешь затылки титанам. Три фракции, девять героев отряда, умения с уровнями и боссы-шифтеры.

**Играть:** https://bromoma.github.io/aot-survivors/

Управление: WASD — полёт на тросах, Пробел — атака по затылку, Esc — пауза, M — звук.

Некоммерческий фан-проект. Авторы шрифта, музыки и звуков — в [CREDITS.md](CREDITS.md).
